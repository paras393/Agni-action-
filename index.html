A NOTE ON INTERPRETATION

How to read this signal

Each glowing point represents an illustrative fire observation record. Repeated points in the same area form a recurring cluster. Brighter colour represents a stronger visual priority in this prototype. Confidence is inherited from the local demo data.

This visual pattern is not proof of an individual farmer’s action. Real deployment would require filtered NASA FIRMS data and human verification.
